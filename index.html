LeakSpot

A serverless system that helps cities find and fix hidden water leaks, so crews fix the worst leak first.

I built it solo on AWS for the WeMakeDevs × AWS Bharat Builds hackathon (Heat & Water track). It brings together meter data, citizen photo reports checked by AI, and a fair priority score. A repair only counts as done when the meters prove the leak has stopped.

  • AWS Lambda
  • Amazon Bedrock
  • Amazon DynamoDB
  • AWS CDK
  • React
  • three.js
Live demo Video Write-up GitHub
  • Every 15 min each area's water in and water used is compared against its own 14-day pattern.
  • No app, no login for citizen photo reports, checked by Amazon Bedrock in English, Hindi and Marathi.
  • 0 to 100 explainable priority score for every leak.
  • 3 clean readings before a ticket closes. If the leak is still there, it reopens by itself.
